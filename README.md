## Featured projects

### [SnakeFusion Python](Snakes/SnakeFusion/SnakeFusionPython/)

A Python port of a Processing-based Snake project that uses evolving neural-network-controlled snakes and a fusion mode. It demonstrates Python modularity, Pygame rendering, CSV-backed model data, vectors, matrix operations, and evolutionary-programming concepts. See the [project README](Snakes/SnakeFusion/SnakeFusionPython/README.md) for setup and controls.

### [SnakeAI](Snakes/SnakeAI/GoodSnakeAI2/)

An iterative Snake AI project with neural-network, population, mutation, and fitness components. It includes a headless smoke test for exercising generations without opening a game window. It demonstrates object-oriented design, algorithmic experimentation, and test-oriented thinking. See the [project README](Snakes/SnakeAI/GoodSnakeAI2/README.md).

### [Pygame Game Coursework](IST-242/pythongametest/)

A course game project using Pygame, event handling, sprites, collision logic, and sound effects. It is presented as coursework, not as a production game. See the [project README](IST-242/pythongametest/README.md).
